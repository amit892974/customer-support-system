
# Customer Return and Refund Policy

## Electronics
- Customers may request a return for damaged or defective products.
- The product must satisfy the configured return window.
- Refund amount cannot exceed the original order amount.

## Fashion
- Products must be unused and in returnable condition.
- The product must satisfy the configured return window.

## General
- Order ownership must be verified before processing any refund.
- Orders outside the return window are not eligible.
- Duplicate refund requests are not allowed.
- Refunds above INR 5000 require human approval.
- Refunds are simulated locally. No real payment is issued.

## Important
The return window is a configurable application setting.
The demo currently assumes 30 days from delivery.
This is a demonstration assumption, not a policy duration specified by the assignment.
